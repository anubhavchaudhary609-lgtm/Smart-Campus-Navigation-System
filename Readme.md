# Smart Campus Navigation System

A web-based Smart Campus Navigation System designed to help students, faculty, and visitors easily explore the campus and locate important campus facilities.

## Project Overview

The Smart Campus Navigation System provides an interactive and user-friendly interface for exploring different locations within a campus.

The system is developed as a frontend web application using HTML, CSS, and JavaScript, with an interactive map to support campus navigation.

## Features

- Interactive campus map
- Easy identification of important campus locations
- Interactive navigation elements
- User-friendly interface
- Clean and responsive design
- Campus information organized in an accessible manner

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Leaflet.js
- OpenStreetMap

## How to Run the Project

1. Clone the Repository
```
git clone https://github.com/anubhavchaudhary609-lgtm/Smart-Campus-Navigation-System.git
```
2. Open the Project

Open the downloaded project folder in Visual Studio Code.

3. Run the Project

Open index.html in a web browser.

For development, you can also use the Live Server extension in Visual Studio Code.
